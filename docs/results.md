## Контрольный запуск

Результаты получены 31 октября 2026 года на сохранённых таблицах прежнего протокола. Я повторно обучил четыре классификатора и пересчитал bootstrap. Новый полный поиск Optuna и полный прогон с исправленными временными зазорами не входят в этот запуск.

| Модель | Признаков | NDCG@10 val | NDCG@10 test | Recall@10 val | Recall@10 test |
|---|---:|---:|---:|---:|---:|
| Ручная, стандартные параметры | 61 | 0,083245 | 0,097539 | 0,106468 | 0,124424 |
| Ручная, сохранённые параметры Optuna | 61 | **0,094114** | 0,095070 | **0,117405** | **0,125752** |
| Автоматическая, стандартные параметры | 151 | 0,085212 | 0,091007 | 0,115025 | 0,119185 |
| Автоматическая, сохранённые параметры Optuna | 151 | 0,089725 | **0,097770** | 0,115339 | 0,123910 |

Источник: [results_recheck.csv](../reports/recheck/results_recheck.csv). Жирным выделен максимум столбца, а не статистически значимая победа.

![Основное сравнение и доверительный интервал](assets/results.png)

По val среди ручных вариантов выбирается модель с сохранёнными параметрами Optuna. Её test ниже, чем у стандартной ручной модели; переключаться на последнюю после просмотра test означало бы выбирать по тестовой выборке. Среди автоматических вариантов по val также выбирается вариант с сохранёнными параметрами. По val обеих семей лучше ручная модель, по test выбранная автоматическая имеет более высокий NDCG и более низкий Recall.

## Неопределённость результата

Основное сравнение: автоматическая модель с сохранёнными параметрами минус соответствующая ручная модель.

| Показатель | Значение |
|---|---:|
| Точечная разность NDCG@10 test | +0,002700 |
| Относительная разность | +2,84% |
| Среднее bootstrap | +0,002617 |
| 95% percentile-интервал | [−0,004240; +0,009805] |
| Повторов / seed | 2000 / 42 |
| Пользователей с позитивом на test | 1656 |

Источник: [bootstrap_recheck.json](../reports/recheck/bootstrap_recheck.json).

**Вывод:** точечная оценка поддерживает дальнейшее исследование генератора, но статистически подтверждённого превосходства нет. Эквивалентность и гарантированное отсутствие проигрыша также не установлены.

## Ранние эксперименты

| Модель | NDCG@10 val | NDCG@10 test | Recall@10 test |
|---|---:|---:|---:|
| Ручная, стандартные параметры | 0,0777 | 0,0852 | 0,1136 |
| Автоматическая, стандартные параметры | 0,0812 | 0,0848 | 0,1151 |
| Ручная, исторический Optuna | 0,0837 | 0,0883 | 0,1181 |
| Автоматическая, исторический Optuna | 0,0820 | 0,0909 | 0,1186 |

Источник: [исторический JSON Optuna](../reports/historical/optuna_results.json). Историческая разность настроенных моделей +0,0026; среднее bootstrap в JSON +0,001726, CI [−0,002900; +0,007123]. Среднее bootstrap и разность исходных метрик — разные статистики. Причину величины расхождения без исходных предсказаний установить нельзя.

Числа контрольного запуска отличаются от ранних: фиксирован seed обучения, изменено правило точных ничьих; полное исходное окружение не сохранено. По агрегатам нельзя определить вклад каждой причины, поэтому эти серии не объединяются.

В ранних экспериментах top-37 и корреляционный отсев не показали устойчивого преимущества. LambdaRank auto-all превосходил ручной ранкер, но не дал подтверждённого выигрыша относительно лучшей ручной классификационной модели. Исторический auto-pruned относительно расширенной ручной модели имел интервал ниже нуля; обобщение «все различия незначимы» некорректно.

## Что можно утверждать

Генератор реализован и проверен на общих с ручным кодом признаках в синтетическом тесте. Сравнение моделей выполнено на согласованных строках и метках. Подготовлен следующий временной протокол, устраняющий найденные пограничные проблемы часовой метки.

Пока нельзя утверждать доказанное повышение качества, снижение трудозатрат, готовность к промышленной эксплуатации или воспроизводимость полного исторического Optuna-поиска. Приоритет следующего эксперимента — пересборка с часовыми зазорами, одинаковый новый подбор, несколько seed и новый временной test.
