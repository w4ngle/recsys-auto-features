# Экспериментальные ноутбуки

[← О проекте](../README.md) · [Инструкция запуска](../docs/reproduction.md)

- **[T-Lab.ipynb](T-Lab.ipynb)** — основной последовательный эксперимент: загрузка шести таблиц, проверка соответствия строк, четыре классификатора и парный bootstrap. В репозитории сохранены небольшие выводы контрольного запуска.
- **[T-Lab.original.ipynb](T-Lab.original.ipynb)** — архив исследовательских итераций, включая top-37 и LambdaRank. Зависит от промежуточного состояния и не предназначен для линейного воспроизведения основного эксперимента.

Основной ноутбук запускать из корня проекта или `notebooks/`, используя окружение проекта. Данные по умолчанию читаются из `data/`; другую папку можно указать через `RECSYS_DATA_DIR`.

`RUN_SEARCH=False` повторно применяет сохранённые исторические параметры. `True` запускает новый поиск с бюджетом `N_TRIALS`; для каждого нового запуска нужен уникальный `STUDY_TAG`.

Результаты пишутся в `reports/recheck/` с заменой прежних файлов. Перед новой серией сохранить предыдущие результаты отдельно. Полный прогон с часовым зазором требует предварительной пересборки через `prepare_data.py`.
